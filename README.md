## ¿Qué es NexoClaro?
Aplicación móvil inclusiva (iOS y Android) con **Google Gemini** y base de datos estructurada **SQLite** que explica, traduce y guía paso a paso a adultos mayores, migrantes, estudiantes de primera generación y comunidades con baja conectividad para acceder a **becas, trámites oficiales, salud y empleo**.
