2. Esquema de Base de Datos Estructurada (SQLite / MySQL Compatible)

perfil_usuario

  • PK id (INT)
  • nombre (VARCHAR)
  • grupo_objetivo (VARCHAR)
  • idioma (VARCHAR)
  • nivel_lectura (VARCHAR)
  • texto_grande (BOOLEAN)

servicios

  • PK id (INT)
  • categoria (VARCHAR)
  • titulo (VARCHAR)
  • resumen_claro (TEXT)
  • requisitos (TEXT)
  • fuente_oficial (VARCHAR)

pasos_servicio

  • PK id (INT)
  • FK servicio_id (INT → servicios.id)
  • orden (INT)
  • instruccion (TEXT)
  • completado (BOOLEAN)

consultas_ia

  • PK id (INT)
  • FK perfil_id (INT → perfil_usuario.id)
  • pregunta (TEXT)
  • respuesta_gemini (TEXT)
  • idioma (VARCHAR)
  • fecha (DATETIME)
