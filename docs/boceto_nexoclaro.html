2. Flujo Técnico de Datos e Inteligencia Artificial
1

Entrada Multimodal

El usuario escribe o graba una nota de voz con sus propias palabras desde la app móvil.

2

Contexto desde SQLite

La app consulta perfil_usuario para obtener idioma, grupo objetivo y nivel de lectura.

3

Procesamiento Gemini

Gemini 2.5 Flash traduce, elimina tecnicismos y estructura la respuesta en pasos claros.

4

Voz + Checklist Offline

Se lee en voz alta con expo-speech y se guarda en SQLite para uso sin internet.

3. Esquema de Base de Datos Estructurada (SQLite / MySQL Compatible)

perfil_usuario Tabla 1

  • PK id (INT)
  • nombre (VARCHAR)
  • grupo_objetivo (VARCHAR)
  • idioma (VARCHAR)
  • nivel_lectura (VARCHAR)
  • texto_grande (BOOLEAN)

servicios Tabla 2

  • PK id (INT)
  • categoria (VARCHAR)
  • titulo (VARCHAR)
  • resumen_claro (TEXT)
  • requisitos (TEXT)
  • fuente_oficial (VARCHAR)

pasos_servicio Tabla 3

  • PK id (INT)
  • FK servicio_id → servicios.id
  • orden (INT)
  • instruccion (TEXT)
  • completado (BOOLEAN)

consultas_ia Tabla 4

  • PK id (INT)
  • FK perfil_id → perfil_usuario.id
  • pregunta (TEXT)
  • respuesta_gemini (TEXT)
  • idioma (VARCHAR)
  • fecha (DATETIME)
