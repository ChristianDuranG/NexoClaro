2. Arquitectura Multimodal y Offline
1

Voz o Texto

El usuario habla al micrófono o escribe su duda sin tecnicismos.

2

Perfil en SQLite

Se lee idioma, grupo objetivo y nivel de lectura desde perfil_usuario.

3

Gemini 2.5 Flash

Traduce, simplifica y devuelve pasos accionables adaptados al usuario.

4

Voz + Checklist

Se narra en voz alta y se guarda en SQLite para consultarlo sin internet.

3. Base de Datos Estructurada (SQLite / MySQL)

perfil_usuario Tabla 1

  • PK id (INT)
  • nombre (VARCHAR)
  • grupo_objetivo (VARCHAR)
  • idioma (VARCHAR)
  • nivel_lectura (VARCHAR)
  • texto_grande (BOOLEAN)

servicios Tabla 2

  • PK id (INT)
  • categoria (VARCHAR)
  • titulo (VARCHAR)
  • resumen_claro (TEXT)
  • requisitos (TEXT)
  • fuente_oficial (VARCHAR)

pasos_servicio Tabla 3

  • PK id (INT)
  • FK servicio_id → servicios.id
  • orden (INT)
  • instruccion (TEXT)
  • completado (BOOLEAN)

consultas_ia Tabla 4

  • PK id (INT)
  • FK perfil_id → perfil_usuario.id
  • pregunta (TEXT)
  • respuesta_gemini (TEXT)
  • idioma (VARCHAR)
  • fecha (DATETIME)
